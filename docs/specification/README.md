# Prototype specification

The current specification is
[**0.1-r2**](board-simulator-prototype-0.1-r2-spec.md), updated on 2026-11-22.
Use it for new implementation and reviews.

[0.1-r1](board-simulator-prototype-0.1-spec.md) is the preserved 2026-11-18
baseline. Its GCC/C11 default, late UI order, and proposed-license wording were
superseded by accepted decisions in r2. Its digital, time, HAL, fault, and reset
contracts were retained.

The specification states the target behavior. See [current status](../status.md)
for implementation evidence and [architecture](../architecture.md) for the
responsibility boundaries. Neither the specification nor a source review is a
claim that the full prototype has passed acceptance checks.
