# Contributing

This is a small hobby project, and I'm learning as I go. Ideas, bug reports, and
help with the code are welcome.

For a bigger change, let's discuss the idea first. There's a lot I want to try,
but I'd like to get the small button-and-LED example working before adding more.

A few things that help:

- Keep each change focused on one thing.
- Write clear, readable code and follow the style already in the project.
- Build it and try the part you changed.
- Explain what you changed and how you checked it.
- Use English for text shown in the app.

See the [README](README.md) for how to run the project. The [docs](docs/architecture.md)
have more detail about the plans if you need it.
